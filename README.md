# Rishi's Clock

My Hack Club project. It's like a mini desktop in the browser with Avengers theme.

Made with just HTML, CSS and JS. No frameworks or anything.

### What's inside
- `index.html` - the main page. Has live IST clock + date at top, Avengers background, and a dock at the bottom.
- `timer.html` - A countdown timer. You can type minutes and set your own time, start / stop / reset.
- `stopwatch.html` - normal count-up stopwatch with start / stop / reset.
- `404.html` -A simple 404 page with a back home button.
- images - `avengers background.jpg`, `Age.jpg`, `infinitywar.jpg` for backgrounds, plus `start.png`, `stop.png`, `reset.png`, `timer.png`, `stopwatch.png` for buttons/icons.

### How it works
Open `index.html` and you get the clock. Click the Timer or Stopwatch icons in the dock and they open in a window on top. You can minimize or close the window.

Clock is set to Asia/Kolkata time.

### How to run
Just download this and open `index.html` in your browser. Thats it. No install needed.

Double click -> done.
